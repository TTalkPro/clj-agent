# T-05 exec + HeadTailBuffer + 有状态 exec 会话

> 设计依据：[designs/tools-module.md](../designs/tools-module.md) §8。依赖：T-01
> 状态：✅（日期 2026-11-08）

## 范围
- `IExecBackend`（起进程 ⇒ `java.lang.Process`）+ `local-backend` + `argv-prefix-backend`（接 bwrap 等）；`ICommandRunner`（单发跑完）+ `backend-runner`。
- `exec`：argv、缺省 10 s、超时杀进程树 + 退出码 124、stdin 关闭、固定环境 `NO_COLOR/TERM=dumb/LANG,LC_*=C.UTF-8/COLORTERM=/PAGER,GIT_PAGER,GH_PAGER=cat`、输出头尾保留 + 给模型的结果文本（退出码 / 耗时 / 总行数 / 输出）。
- HeadTailBuffer：头尾各半、中间丢弃计数、省略标记。
- `exec_command` / `write_stdin`：yield 收集、空串轮询（≥ 5000 ms）、`\u0003` 中断、退出后交出退出码再摘掉、64 会话 + 最近 8 个保护 + 先驱逐已退出的；`close!` 收尾。
- 开 `:exec` 必须显式给后端（⛔ 缺省后端）。Keelson.Agent.Sandbox 不移植。

## 验收
- HeadTailBuffer 各边界；exec 成功 / 非零 / 超时 / 环境 / stdin EOF / 截断 / 越界 / 起不来；argv 前缀后端与自定义 runner；会话交互 / 轮询 / 中断 / 未知 id / close!；驱逐规则与 yield 夹取单测。
