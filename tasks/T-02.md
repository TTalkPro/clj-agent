# T-02 read_file / write_file / list_dir / glob / grep / delete_path

> 设计依据：[designs/tools-module.md](../designs/tools-module.md) §5。依赖：T-01
> 状态：✅（日期 2026-11-08）

## 范围
- `read_file`：`L{n}: ` 前缀、offset/limit 分页（缺省 2000）、单行 500 字节字符边界截断、indentation 模式（Codex read_block 逐行照搬）；流式读、tag 按整篇算；输出头 `[路径#TAG]` 并登记。
- `write_file`：新建直接写；覆盖过新鲜度闸、按原换行/编码/BOM 写回；语法闸。
- `list_dir`（BFS、排序、分页、`/ @ ?`）、`glob`（JDK glob + `**/` 零级目录补丁 + 忽略规则）、`grep`（有 `rg` 用 `rg`，结果再过策略；否则 JVM 正则带超时、跳隐藏 / 二进制 / 忽略）。
- `delete_path`：非空目录要 recursive；链接只删链接（指向根外的链接按所在目录判）；根与祖先拒删；不存在算成功。

## 验收
- 每个工具在临时目录下有正反例；grep 两套引擎跑同一组断言。
