# T-07 写后语法守卫（「不更糟」闸）

> 设计依据：[designs/tools-module.md](../designs/tools-module.md) §6。依赖：T-02、T-03、T-04
> 状态：✅（日期 2026-11-08）

## 范围
- `ISyntaxChecker` 协议（`handles?` / `check`；nil = 看不了，[] = 没问题）、`checker` / `for-extensions` 造检查器；宿主的排在内置前面。
- 内置：JSON（Jackson；JSONC 家族允许注释与尾逗号；顶层多余内容）、EDN 与 Clojure 源码（Clojure 读取器，未闭合报起始行；`::alias/kw` 等判不了 ⇒ nil）、XML（JDK SAX，禁 DTD，带 DOCTYPE ⇒ nil）。
- 判据「更糟」：before 看得了且 after 问题更多才拒；接进 write_file / edit_file / apply_patch（整份拒）与审批预览尾巴。
- BracketScan.cs 不移植（理由见设计 §6）。

## 验收
- 三类检查器正反例、宿主检查器优先、检查器抛异常 ⇒ 放行、0→1 拒 / 1→1 放 / 1→0 放 / 新文件不判 / 闸关、预览两种尾巴；三个写工具各有一个「改坏被拒且文件不动」的用例。
