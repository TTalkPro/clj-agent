# T-06 web_fetch / skill / notes

> 设计依据：[designs/tools-module.md](../designs/tools-module.md) §5。依赖：T-01
> 状态：✅（日期 2026-11-08）

## 范围
- `web_fetch`：JDK HttpClient、手动跟随重定向（每跳过 `:allow-url`）、时限、体积上限按实读字节、Content-Type 分流、HTML → 文本（去 script/style、取 main/article、标题 / 列表 / 链接）、max_chars 截断；缺省敏感、可按实例关。
- `skill`：技能目录（宿主给）下 `*/SKILL.md`；frontmatter 子集解析；说明在绑定时扫描生成；装载正文 + 基目录 + 旁边文件。
- `notes_*`：`INotesStore` 协议 + `dir-store` / `memory-store`；名字校验防路径逃逸；`notes_write` 缺省不敏感、可开。

## 验收
- web_fetch 用本地 `com.sun.net.httpserver.HttpServer` 覆盖 HTML / JSON / 二进制 / 截断 / 重定向 + 拦截 / 重定向环 / 非 2xx / 体积上限 / URL 校验 / 敏感开关；skill 覆盖同名优先、无 name、非法名、装载；notes 两个存储各跑一遍。
