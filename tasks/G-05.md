# G-05 取消原因 + 孤儿自动停

> 设计依据：[designs/agui-borrow.md](../designs/agui-borrow.md) §5。依赖：无。
> 状态：✅（2026-11-08）

## 范围

- `event/request-stop!` 加 `reason`（缺省 `:stop`，第一个原因算数），新增 `event/stop-reason`、`event/stop-reasons`。
- `runtime`：`stop!` 4-arity `(stop! rt conv-id run-id reason)`；supersede ⇒ `:superseded`，`shutdown!` ⇒ `:shutdown`；`:run/cancelled` 带 `:reason`；`run-status` 带 `:cancel-reason`；新选项 `:orphan-cancel-ms`（缺省 0 = 关）。
- `codec`：`RUN_FINISHED.result.reason`（有原因才写）。
- 路由 `start!` 透传 `:orphan-cancel-ms`。

## 验收

- stop / supersede / shutdown 三种原因落在终态与 run-status 上；第一个原因算数；1-arity 老调用点不变。
- 孤儿：到点无人 ⇒ `:orphan`；走了又回来 ⇒ 不停；缺省关 ⇒ 照跑完。
