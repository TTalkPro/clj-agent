# P-05 并发准入票据池

> 设计依据：[designs/provider-reliability.md](../designs/provider-reliability.md) §5。依赖：P-02（每次尝试取票）
> 状态：✅（日期 2026-11-08）

## 范围

- core 新 ns `im.ttalk.agent.admission`：`admission`、`acquire!`、`acquire-async`、`release!`、`with-permit`、`with-permit-async`、`in-flight`、`waiting`。
- `chat-model/with-admission`：DefaultChatModel 每次尝试取票（退避不占票）；其它 ChatModel 用 `AdmittingChatModel` 装饰整次调用。

## 验收

- 票数上限与 FIFO 移交；release 幂等；异步取票不占线程；中断归还。
- DefaultChatModel 退避期间 in-flight = 0；流式整条流占票。
