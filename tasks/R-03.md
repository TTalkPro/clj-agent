# R-03 同参失败保护 + 失败摘除（tool-guard-filter）

> 设计依据：[designs/runtime-borrow.md](../designs/runtime-borrow.md) §3。依赖：react 框架挂点「工具侧请求停回合」(`:loop/stop`)、context 框架槽 reducer。
> 状态：✅（2026-11-08）

## 范围

- core `im.ttalk.agent.filter.tool-guard`：参数规范化指纹、repeat-limit 提醒、repeat-stop-limit 停回合、连续失败门禁拒绝（工具留在列表）。
- core `context`：`framework-slots`（`:tool-guard/state` 两层 merge）、`framework-keys` 增 `:tool-guard/state` `:loop/stop` `:loop/notes`。
- react：批后见 `:loop/stop` 以 `:completed` 收尾并补落库工具结果。

## 验收

- 第 N 次同参失败结果含「别再原样重试」+ 原报错；N+1 次停回合（`:stopped-by :tool-guard`）。
- 成功清零；连续失败后调用不执行直接拒。
- 计数经暂停快照 EDN 往返后保持。
