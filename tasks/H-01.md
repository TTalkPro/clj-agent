# H-01 clj-http 模块骨架 + client 构造 + 请求入口 + 头工具

> 设计依据：[designs/http-module.md](../designs/http-module.md) §3 §4.1 §4.2 §4.4（头工具）。依赖：无
> 状态：✅（2026-11-09）

## 范围
- 新建模块 `modules/clj-http`（`:deps` 只有 `org.clojure/clojure`），接进 `bb.edn` modules（排在 core 之前或之后均可，无内部依赖）、
  根 `deps.edn` `:paths` / `:test`、`tests.edn`、`build.clj` 模块表（无 `:override-libs`）、`.github/workflows/test.yml` matrix、
  `scripts/check_docs.clj`（登记模块 README）、`modules/README.md`。顺带确认 mcp 不在 `bb.edn` / CI matrix 里是否有意（§8）。
- `im.ttalk.http`：`client`（`:connect-timeout-ms` `:version` `:executor` `:redirect` `:proxy`——`:proxy` 本任务只收
  `nil` / `ProxySelector`，`:env` / 串在 H-02 接上）、`default-client`（delay；HTTP/1.1 + 虚拟线程 + connect 30s，与现
  `provider.http.client/default-client` 等价）。
- `request` / `request-async`：请求 map ⇒ `HttpRequest`（唯一一处）；`:query-params`（沿用 `build-url` 的编码）；
  有 body 且无 Content-Type ⇒ 补 `application/json`；受限头静默丢；`:as` `:string` / `:bytes` / `:input-stream` / `:discard`；
  响应头 = 小写名 ⇒ 串向量（去 HTTP/2 伪头）。
- 头工具移植自 clj-net `net.http`：`header` `header-values` `assoc-header` `dissoc-header` `media-type` `charset`。

## 验收
- 本机回环服务（`com.sun.net.httpserver.HttpServer`，JDK 自带，不加测试依赖）上覆盖：五种方法、query 编码、缺省 Content-Type
  与显式 Content-Type 不被覆盖、受限头不抛、四种 `:as`、多值响应头、同步 IO 失败抛 `IOException`、异步失败异常完成。
- 头工具：大小写不敏感、串 / 串向量 / `java.util.List` 三种值形状都取得到第一个值（钉住 provider-reliability.md §1.3 那个 bug）。
- `bb test http` 全绿；`bb check-docs` 全绿。
