# R-13 pause_turn 续跑

> 设计依据：[designs/runtime-borrow.md](../designs/runtime-borrow.md) §13。依赖：无。
> 状态：✅（2026-11-08）

## 范围

- react：`:pause` 响应原样续跑（无新 user 消息），扣预算，耗尽按当前响应收尾；`:settings :pause-turn-fn` 可覆盖判定。

## 验收

- pause→续跑→最终文本；续跑请求无新增 user 消息；预算耗尽不抛。
