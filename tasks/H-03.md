# H-03 按行真流式 stream-lines（watchdog / 取消 / 单次终止）

> 设计依据：[designs/http-module.md](../designs/http-module.md) §4.3。依赖：H-01
> 状态：✅（2026-11-09）

## 范围
- `http/stream-lines`：把 `provider/http/stream_client.clj` `post-stream-async` 的**传输部分**搬下来——
  `fromLineSubscriber`、2xx / 非 2xx 分流（非 2xx 收错误体串，不调 `:on-line`）、`:on-response`、
  共享 watchdog 单线程（daemon，「到点检查 → 按剩余时间重排」）、`:first-byte-ms` / `:idle-ms`、`cancel` 同时取消 subscription 与 future、
  `done?` CAS 保证终止只发生一次。
- 返回 `{:future CompletableFuture<{:status :headers [:body]}> :cancel fn}`；超时以
  `(ex-info … {:im.ttalk.http/timeout :first-byte|:idle :limit-ms n})` 异常完成。
- 不含任何 canonical error / parse-fn / 模型核对 / 限流——那些在 H-04 留在 provider。

## 验收
- 回环服务上：逐行实时到达（第一行到达时服务端还没写第二行，用闸门 promise 断言，不用 sleep 赌）、
  非 2xx 错误体与响应头、首字节超时、空闲超时（心跳注释行续命）、`:on-line` 里调 `cancel`、取消后不再回调、
  超时与正常结束竞争时只终止一次。
- 现 `stream_client_test.clj` 中纯传输层的用例迁到 http 模块后照过。
- `bb test http` 全绿。

  H-04 后一条不改照过。
