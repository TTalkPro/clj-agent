# G-07 入参校验与 HTTP 面补齐

> 设计依据：[designs/agui-borrow.md](../designs/agui-borrow.md) §7。依赖：G-04、G-06。
> 状态：✅（2026-11-08）

## 范围

- `codec/run-input-problem`：非对象 ⇒ `bad_json`，缺 threadId ⇒ `missing_thread_id`，`/run` 缺 runId ⇒ `missing_run_id`（只出数据，不出状态码）。
- `codec/run-info` 新增 `:thread-endpoints {:list :inspect :mutations}` 逐格覆盖。
- 路由：读体有上限（`:max-body-bytes`，缺省 16 MiB，超了 413 `body_too_large`）；坏 JSON 400 `bad_json`；错误统一 `{"error","message"}`；`/stop` 回 `{stopped:true, interrupt:{type:"RUN_ERROR", message:"Run stopped by user", code:"STOPPED"}}` / `{stopped:false, message}`；`/threads` 认 `agentId` / `includeArchived` / `limit` / `cursor`，缺省隐藏归档；缺槽 501 `not_implemented`（`/info.threadEndpoints` 出自同一份槽位事实）；改名 / 归档目标不存在 404 `thread_not_found`；`PATCH /threads/:id` 与 POST 同义，CORS 方法表加 PATCH；`GET /threads/:id` 回单条。

## 验收

- codec 真值表；路由 400 / 413 / 404 / 501 / stop 两种响应体 / 过滤 / 分页 / 归档隐藏。
