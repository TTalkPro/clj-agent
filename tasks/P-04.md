# P-04 流式首字节 / 空闲超时 + 回包模型名核对

> 设计依据：[designs/provider-reliability.md](../designs/provider-reliability.md) §4。依赖：P-01
> 状态：✅（日期 2026-11-08）

## 范围

- `stream-client/post-stream-async`：`:first-byte-ms` / `:idle-ms` watchdog（共享调度器、按剩余时间重排）、终止回调只一次、`:check-model`、`:on-headers`。
- `post-stream-sync` / `post-stream-deferred` 透传；openai 兼容、anthropic、responses、dashscope 从 config 透传。
- 同步 `success-body` 核对 `:check-model?`。

## 验收

- 首字节超时 → `:timeout-error`（`:code :first-byte-timeout`，可重试）；吐字后静默 → `:idle-timeout`；心跳行续命。
- 模型名不一致 → `:provider-error` `:code :model-mismatch`、不投递 token。
- 不配不生效（向后兼容）。
