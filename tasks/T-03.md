# T-03 edit_file 精确替换 + ReadFreshness 读写新鲜度闸

> 设计依据：[designs/tools-module.md](../designs/tools-module.md) §5 §6。依赖：T-01、T-02
> 状态：✅（日期 2026-11-08）

## 范围
- `edit_file`：精确原文；不唯一拒并列行号（≤ 20）；`all=true` 全换；0 匹配三种诊断（行号前缀 / 只差空白附行号 / 先 read_file）。
- 新鲜度：已读表（FNV-1a 32 tag，`"hello"` ⇒ `4F9F2CAB`）；登记点 = read_file 头 + 写类工具回的新 tag；没读过 / 读后被改 ⇒ 拒；新建不要求读过；`:read-tracking? false` 关闭。
- `EditableText`：UTF-8（含 BOM）、带 BOM 的 UTF-16/32、严格 GBK；CRLF/CR 保留；二进制 / 未知编码拒。

## 验收
- 唯一 / 多处 / all / 三种诊断 / 新鲜度两种拒绝 / CRLF+BOM 原样写回 / 语法闸拒绝，全部有测试。
