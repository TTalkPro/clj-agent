# G-08 事件存储可替换挂点（EventStore）

> 设计依据：[designs/agui-borrow.md](../designs/agui-borrow.md) §8。依赖：G-06。
> 状态：✅（2026-11-08）

## 范围

- 新 ns `im.ttalk.agent.agui.event-store`：`EventStore` 协议（`es-append!` / `es-since` / `es-events` /
  `es-last-seq` / `es-release!` / `es-delete!`）、缺省 `ring-store`、共用 `since-of`、runtime 侧 `safe-*` 包装。
- runtime：会话条目去掉内置 `:buffer`，改走 `:event-store`（缺省 `(ring-store {:buffer-size ..})`）；
  新会话 `:seq` 从 `es-last-seq` 接上；驱逐 / `forget!` / `shutdown!` 调 `es-release!`；新 `rt/purge!`。
- examples 路由：删除线程、清空线程改用 `rt/purge!`。
- 本库**不带**持久化实现（用户拍板）。

## 验收

- 不配 `:event-store` 时行为与之前逐字相同（原有 agui / examples 测试全绿）。
- 插入模拟的外部持久化实现：新建 runtime 后事件仍可读、`:since` 跨进程续传、序号不从 0 重来；
  `forget!` 不删、`purge!` 才删；存储抛异常不打断 run。
