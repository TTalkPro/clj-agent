# G-06 线程元数据持久化

> 设计依据：[designs/agui-borrow.md](../designs/agui-borrow.md) §6。依赖：无。
> 状态：✅（2026-11-08）；事件持久化不做（用户拍板），事件存储改为可替换挂点见 [G-08](G-08.md)

## 范围

- 新 ns `im.ttalk.agent.agui.thread-store`：`ThreadStore` 协议（`ts-slots` / `ts-touch!` / `ts-get` / `ts-list` / `ts-update!` / `ts-delete!`）、`in-memory-store`、共享的列表语义 `normalize-query` / `list-page` / `apply-updates`、`has-slot?`。
- 新 ns `im.ttalk.agent.agui.thread-store.sqlite`（按需加载）：`sqlite-thread-store`，表 `agui_threads`。零新依赖（`next.jdbc` 来自 client）。
- 路由：`/run` 起跑成功即 `ts-touch!`（带 agentId）；`/threads` 列表改读线程存储；`start!` 的 `:threads? true` 缺省进程内存储，`:thread-store` 可换。
- ⛔ 不存消息、不存事件（`docs/agent-runtime-design.md` §8.1 / §8.2）。事件持久化不做（2026-11-08 用户拍板），事件存储做成可替换挂点，见 G-08。

## 验收

- 两个实现跑同一组契约用例；sqlite 关掉重开仍在；路由层驱逐（`rt/forget!`）后 `/threads` 仍列出。
