# H-10 Apache HttpClient transport adapter

> 设计依据：[designs/provider-http-transport.md](../designs/provider-http-transport.md) §2 §7.2 §8.1 §9。依赖：H-07 H-08 H-09
> 状态：✅（2026-11-18）

## 范围

- 新增可选模块 `modules/clj-http-apache`，坐标 `im.ttalk/clj-http-apache`，ns `im.ttalk.http.apache`。
- 按仓库现有模块登记方式接进 `bb.edn`、根 `deps.edn`、`tests.edn`、`build.clj`、CI matrix、`scripts/check_docs.clj`、
  `modules/README.md`；Apache 依赖只进该模块，不进 `clj-http`、provider、core。
- 实现 `http-apache/transport`，底层优先使用 Apache HC5 async client：
  - 不另建阻塞 client 当主路径；
  - 同步入口包装 async future；
  - `request-async` 返回 `CompletableFuture`；
  - `stream-lines` 返回 `{:future :cancel}`。
- 构造选项：
  - `:connect-timeout-ms`；
  - `:request-timeout-ms`；
  - `:pool`；
  - `:redirect`；
  - 其他 Apache client 配置用白名单选项显式暴露，不把原生 config 对象直接塞进 provider 配置。
- Apache 异常归一成 H-07 transport exception；不得把 Apache 类型或原生异常直接泄漏到 provider。
- SSE 用 async response consumer 增量吐行；不得整包收完后再回调。
- 实现 first-byte / idle watchdog；超时、取消、`:on-line` 异常、单次终止语义与 JDK adapter 相同。
- `transport/close` 关闭 Apache client 与关联资源；provider 不自动关闭。

## 验收

- Apache transport 通过 H-07 contract facade 与 H-08 同一组 transport contract test。
- 回环服务覆盖：
  - 同步 / async / stream 三条路径；
  - 多值响应头；
  - 非 2xx 错误体；
  - first-byte timeout；
  - idle timeout；
  - cancel 传播并释放 response；
  - 连接失败、DNS 失败、超时的 transport error kind。
- provider 可用 `:http-transport (http-apache/transport ...)` 跑通四条路径；缺省 provider 依赖不变。
- `bb test http` 与 `bb test http-apache` 全绿；`bb test provider` 全绿；`bb test` 全绿。
