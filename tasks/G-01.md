# G-01 审批时改参数（approveWithEdits）+ 拒绝理由透传

> 设计依据：[designs/agui-borrow.md](../designs/agui-borrow.md) §1。依赖：无（见下「与下达判断的差异」）；G-02 依赖本项的 schema。
> 状态：✅（2026-11-08；协调者确认 client 侧已具备后同轮实现）

## 范围

- `codec`：`decision-response-schema` 扩成兼容两套（`decision` 枚举 + `approved` / `editedArgs` / `reason`，`anyOf required`）。
- `codec/run-info`：新增 `:approve-with-edits?`，开了才报 `humanInTheLoop.approveWithEdits true`（缺省 false，不谎报）。
- 路由 `resume-decision` 改成返回 `[decision payload]`：`cancelled` / `approved:false` / `decision` 判拒 ⇒ `"rejected"` + `{:message reason}`；`editedArgs` 是 map ⇒ `"approved"` + `{:args editedArgs}`（**整体替换，不合并**）；其余 ⇒ `"approved"`。不再把客户端 payload 原样透传给 `resume-run!`。
- 修掉现存的隐患：`{approved:false}`（无 `decision` 键）今天被判成**批准**。

## 与下达判断的差异（重要）

下达时认为「需要 client 侧 resume 带替换参数，由 runtime agent 先做」。核对后 **client 侧已具备**：
`react.clj` `resume-approval-batch`（`:approved` + `{:args}` 替换 pending 调用参数；拒绝 + `{:message}` ⇒「已拒绝执行：<理由>」，`docs/hitl-timeline-design.md` §2.1）。
**单条审批**不需要 runtime agent 做任何事，下一轮 agui 可直接实现。多条审批的逐条改参数归 G-02。

## 对 client resume API 的需求

- 无新增。约定：`{:args}` 保持**整体替换**语义（Keelson 明确不合并）；若 runtime agent 将来改成合并，本项要跟着改。
- `:args` 的键是 cheshire 解析出的关键字键，与模型原始调用参数同形，client 不需要再规范化。

## 验收

- codec：schema 形状；`:approve-with-edits?` 开关。
- 路由：`resume-decision` 五行真值表（离线）。
- 端到端：sensitive 工具 + `resume[{payload:{approved:true, editedArgs:{…}}}]` ⇒ 工具收到替换后的参数；`{approved:false, reason:"先退款"}` ⇒ 模型收到「已拒绝执行：先退款」；`{approved:false}` 不再被当成批准。

## 完成记录

- 改：`modules/clj-agent-agui/src/im/ttalk/agent/agui/codec.clj`——`decision-response-schema` 加 `approved` / `editedArgs` / `reason`，`required` 改为 `anyOf [{required:[decision]} {required:[approved]}]`；`run-info` 新增 `:approve-with-edits?`（报 `humanInTheLoop.approveWithEdits`，缺省不报）。
- 改：`examples/copilotkit/http_kit_routes.clj`——`resume-decision` 改为公开、返回 `[decision payload]`（按设计 §1 真值表）；`handle-run` 的审批分支改用它，不再原样透传客户端载荷；`info-opts` 缺省报 `approveWithEdits`（`:approve-with-edits? false` 可关）。
- **隐患修复**：`{approved:false}`（无 `decision`）原先落到缺省「批准」，现在 `approved` 显式为 false（布尔或串 `"false"`）先于一切判成拒绝；拒绝时 `editedArgs` 不生效。
- 测试：`codec_test.clj` 改 schema 断言 + 新增 `approve-with-edits-capability-test`；`examples/copilotkit/http_kit_routes_test.clj` 新增 `resume-decision-test`（真值表，含回归）与 `approve-with-edits-e2e-test`（真 http-kit 两段 `/run`：editedArgs 替换参数、reason 进工具结果、`{approved:false}` 不执行、老 `{decision}` 照旧）。
- 结果：`bb test agui` 108 tests / 732 assertions / 0 failures；examples 离线 24 tests / 149 assertions / 0 failures；`bb check-docs` 通过。
- 偏离：取消（`status=cancelled`）时载荷里的 `reason` / `message` / 字符串也作为理由透传（设计只写了「有才带」，此处明确来源）；字符串载荷判拒时整串当理由。
