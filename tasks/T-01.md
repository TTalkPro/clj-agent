# T-01 clj-agent-tools 模块骨架 + 工作区 / 路径策略 + 工具集合构造

> 设计依据：[designs/tools-module.md](../designs/tools-module.md) §2 §3 §4。依赖：无
> 状态：✅（日期 2026-11-08）

## 范围
- 新建可选模块 `modules/clj-agent-tools`（只依赖 core + cheshire），接进 `bb.edn` modules、根 `deps.edn` `:paths`/`:test`、`tests.edn`、`build.clj` 模块表、`.github/workflows/test.yml` matrix。
- `IPathPolicy` + 缺省 `workspace-policy`（可写根 / 只读根 / 受保护名；字面与解链接两口径；悬空链接按目标解；40 跳判环）、`unrestricted-policy`。
- `IFileLayer` + `local-file-layer`（原子写：同目录临时文件 + ATOMIC_MOVE，写解链接后的真实路径，保留 POSIX 权限）。
- `workspace` 选项收口；`workspace-tools` 按组造工具：每个 deftool var 造一个匿名 var，在函数体内部 binding `*workspace*`。

## 验收
- 越界、`..`、前缀相同的兄弟目录、符号链接逃逸（含悬空链接、不存在的尾段）、受保护名（含经链接写入）、只读根、链接环全部被拒且带码。
- 直接调未绑定的 deftool var ⇒ 明确报「未绑定工作区」。
- `bb test tools` 全绿。
