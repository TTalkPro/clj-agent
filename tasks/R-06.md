# R-06 审批链 + 拒绝熔断 + 审批超时

> 设计依据：[designs/runtime-borrow.md](../designs/runtime-borrow.md) §6。依赖：R-05。
> 状态：✅（2026-11-08）

## 范围

- `chain-approver` / `chain-reviewer` / `timeout-approver` / `denial-breaker` + `record!`。
- `approval-filter` 接入审批者链与熔断（跳闸写 `:loop/stop`）。
- simple-agent：暂停路径的熔断与 `:timeout-ms` 审批超时。

## 验收

- 链：首个表态生效、无人表态拒、某环抛拒。
- 超时是结果。
- 连拒 3 次停回合，只跳一次；暂停超时转拒绝。
