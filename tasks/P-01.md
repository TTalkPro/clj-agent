# P-01 错误细分 + 厂商业务码表

> 设计依据：[designs/provider-reliability.md](../designs/provider-reliability.md) §1。依赖：无
> 状态：✅（日期 2026-11-08）

## 范围

- core `model.error`：新增 `:quota-exhausted-error`（不可重试）/ `:context-overflow-error`（不可重试）/ `:empty-completion-error`（可重试）；402 → 欠费；谓词 `quota-exhausted?` / `context-overflow?` / `empty-completion?`；`rate-limit-error?` 不认欠费 429；`classify-exception` 欠费 → `:environment`；`with-ex-data`。
- provider 新 ns `provider.common.business-codes`（码表照 Keelson `ProviderBusinessCodes.cs`）。
- `http.client/response->error` 过码表、修 Retry-After（头值为 List）、扫 `try again in`；新 `success-body` 查 HTTP 200 业务错（base_resp）。
- `stream-client` 非 2xx 带头走 `response->error`；`build-response` 抛错进 err 通道；`stream/anthropic` 流内 error 事件 → canonical。
- `base.clj` 调 compat 补 `:provider-name`。

## 验收

- insufficient_quota@429 → `:quota-exhausted-error`，ChatModel 不重试（只打 1 次）。
- Anthropic billing_error、智谱 1308-1311、MiniMax 1039/2056（含 HTTP 200）→ 欠费；context_length_exceeded / prompt is too long → 超长。
- 文案不凭空造出限流；Retry-After 字符串与 List 值都生效。
- core / provider 测试全绿。
