# R-04 死循环提醒（dead-loop-filter）+ react 临时提醒挂点

> 设计依据：[designs/runtime-borrow.md](../designs/runtime-borrow.md) §4、§0 挂点 1。依赖：R-03 的 react 改动（`:calls`/`:errors` 进 IterationResult）。
> 状态：✅（2026-11-08）

## 范围

- react：`IterationRequest :notes` → 本轮请求末尾 `<system-reminder>`，不落库（memory filter 展开后追加；无 memory 时拼 delta）。
- react：`:continue` 结果带 `:calls` `:errors`。
- client `im.ttalk.agent.filter.dead-loop`：窗口指纹判打转，挂临时提醒，不阻断。

## 验收

- 连续打转 → 下一轮请求末尾有提醒，store 无痕。
- 有进展清空；新 turn 清零。
