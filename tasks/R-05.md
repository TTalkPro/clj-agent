# R-05 声明式审批策略 + 会话审批缓存

> 设计依据：[designs/runtime-borrow.md](../designs/runtime-borrow.md) §5、§15。依赖：无。
> 状态：✅（2026-11-08）

## 范围

- client `im.ttalk.agent.approval`：决策/strictest、sensitive/rule/hint/strictest 策略、JSON path 谓词与自检、会话缓存、`gate`、`approval-filter`、`->approve-fn`。
- react：gate 可返回 `{:pause {...}}`（带信息暂停）；暂停结果带 `:pending-tools`、loop-state 带 `:pending-ids`；resume payload `:decisions` 逐件决定（含改参数）。
- simple-agent：`:approval` 选项；`{:remember :session}`；缓存随暂停快照保存/恢复。

## 验收

- forbid 不暂停直接拒；prompt 暂停；会话批准后同参数不再暂停；跨重启恢复缓存。
- 一次暂停多条待审批，逐件 approved/rejected/改参数。
