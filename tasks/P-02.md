# P-02 重试增强：空补全独立预算、流式首增量前重试、attempts 记录

> 设计依据：[designs/provider-reliability.md](../designs/provider-reliability.md) §2。依赖：P-01（`:empty-completion-error`）
> 状态：✅（日期 2026-11-08）

## 范围

- `retry/run` / `run-async`：`:empty?` + `:empty-retries`（缺省 1）独立预算、`:retry-gate`、`:record-attempts?`、放弃时 ex-data `:attempts`、`:on-retry` 带 `:kind`。
- `resolve-opts`：`:stream-retries`（缺省 2）；`:retry false` 三格全关。
- `response/empty-completion?`、`response/response-attempts`。
- DefaultChatModel 同步 / 流式 / 异步 / 异步流式四条路径接入；流式传给 provider 的 config 剥掉 `:retry`。

## 验收

- 空补全补打 1 次后成功；仍空 → `:empty-completion-error` 且不消耗 `:max-retries`。
- 流式首 token 前的可重试失败被重试；token 后失败只打 1 次（原有用例不变）。
- 成功响应带 `:attempts`；多次失败后异常 ex-data 带 `:attempts`。
- 同步 / 异步语义等价。
