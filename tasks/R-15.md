# R-15 压缩的可替换挂点：CompactionStore + 写回策略

> 设计依据：[designs/runtime-borrow.md](../designs/runtime-borrow.md) §1.x。依赖：R-01。
> 状态：✅（2026-11-08）

## 范围

- `filter.compaction` 新增 `CompactionStore` 协议（`cs-get` / `cs-put!` / `cs-delete!`）与缺省 `in-memory-store`；
  filter 的 `:store` 选项。只持久 `{:cache :failures}`，瞬时量留在进程内。
- `:write-back` 策略函数 `(fn [conversation-id compacted original])`；`store-write-back` 为现成策略，
  `:write-back-store` 保留为它的语法糖。
- 缺省行为不变：不改写 ChatMemory，摘要缓存进程内 LRU。

## 验收

- 原有压缩测试全绿。
- 模拟外部持久化存储：新建 filter 实例（= 重启）后命中缓存不再调摘要器；存进去的状态 EDN 可往返。
- 存储抛异常时照常压缩、照常回答。
- 自定义写回策略拿到会话 id 与压缩前完整历史。
