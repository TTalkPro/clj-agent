## 范围
- 解析器：边界检查、宽松模式剥 heredoc、逐行状态机（Add / Delete / Update / Move to / `@@` / End of File / Environment ID）。
- 匹配：精确 → 忽略行尾空白 → 忽略两端空白 → Unicode 标点归 ASCII；eof 优先从末尾找。
- 应用：逐行保行尾、插入行用首选行尾；整份补丁先在内存推演（后面的块看得到前面的结果），任一对不上 ⇒ 抛、零写入。
