# H-05 mcp / tools 迁到 clj-http

> 设计依据：[designs/http-module.md](../designs/http-module.md) §5（mcp、tools）§6。依赖：H-01 H-02
> 状态：✅（2026-11-09）

## 范围
- **mcp**：`deps.edn` 加 http 模块；`HttpTransport` 改用 `http/request`（三个必填头、session id 回传逻辑不动）；
  `parse-sse` ⇒ `http.sse/parse-all` 后取第一条能解析成 JSON 的 `:data`；`http-transport` 新增 `:client` / `:proxy`，
  缺省用 `http/default-client`（§6 两条缺省行为变化）。
- **tools**：`deps.edn` 加 http 模块；`web.clj` 的 `client-of` ⇒ `(http/client {:redirect :never :connect-timeout-ms … :proxy (:proxy o)})`，
  `:client` 照收 `HttpClient`；请求走 `http/request {:as :input-stream}`；IO 失败文案按 `http.failure/classify` 细分
  （域名解析失败 / 连不上 / TLS 失败）。手动重定向、`:allow-url`、限量读不动。新增选项 `:proxy` 写进 ns docstring。
- `build.clj` 的 mcp / tools `:override-libs` 加 http 模块。
