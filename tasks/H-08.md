# H-08 JDK transport adapter

> 设计依据：[designs/provider-http-transport.md](../designs/provider-http-transport.md) §3 §7.1 §8.1。依赖：H-07
> 状态：✅（2026-11-18）

## 范围

- 新增 `http/jdk-transport`，把现有 JDK 实现包成 transport map：
  - `:request`；
  - `:request-async`；
  - `:stream-lines`；
  - `:capabilities` 含 `:string`、`:bytes`、`:discard`、`:input-stream`、`:stream-lines`；
  - `:name` 为 `:jdk`。
- 构造选项沿用现 `http/client`：
  - `:connect-timeout-ms`；
  - `:version`；
  - `:executor`；
  - `:redirect`；
  - `:proxy`。
- 保留现缺省行为：HTTP/1.1、虚拟线程 executor、connect 30s、redirect `:never`、不读环境代理。
- 可接收已构造好的 JDK `HttpClient`；该选项只属于 JDK adapter，不是跨实现插件边界。
- JDK adapter 不拥有进程级共享 client 的关闭权；进程共享实例由缺省路径持有，显式创建的实例由宿主 `transport/close`。
- 现有 `http/default-client`、`http/request`、`http/request-async`、`http/stream-lines` API 与行为保持不变。

## 验收

- `jdk-transport` 通过 H-07 contract facade 的基本 request / async / stream 测试。
- contract test 覆盖：
  - 同步与异步响应形状一致；
  - 多值响应头；
  - request body string / bytes；
  - `:as :string` / `:bytes` / `:discard`；
  - 非 2xx 不回调 `:on-line`，future 带错误体；
  - first-byte timeout；
  - idle timeout 且心跳行续命；
  - `cancel` 终止上游；
  - `:on-line` 抛异常后不再回调；
  - 终止竞争只发生一次。
- 不强制所有 JDK 特有能力进入通用 contract test；`:input-stream` 作为 JDK capability 单独测。
- `bb test http` 全绿。
