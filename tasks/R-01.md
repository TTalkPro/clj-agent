# R-01 摘要式上下文压缩（compaction-filter）

> 设计依据：[designs/runtime-borrow.md](../designs/runtime-borrow.md) §1。依赖：R-02（truncate-middle）、provider agent 的 `:context-overflow-error`（判定函数可注入，不阻塞）。
> 状态：✅（2026-11-08）

## 范围

- core `im.ttalk.agent.tokens`：文本/消息/请求 token 粗估。
- client `im.ttalk.agent.filter.compaction`：`threshold`、`safe-cut`、`micro-compact`、`drop-oldest`、`compact`（纯函数）与 `compaction-filter`（`:chat`）。
- 摘要器可注入 + `chat-model-summarizer`；连续失败停用摘要器；超长恢复重发一次；摘要缓存（缺省不写回 store）+ `:write-back?`；`:on-compaction` 观察。

## 验收

- 超阈值先微压缩，仍超才摘要；切点不劈调用/结果对。
- 第二轮命中缓存不再调摘要器；store 缺省不被改写。
- 摘要失败退化丢最老，连续 3 次停用摘要器。
- `:context-overflow-error` 异常 / `:context-window-exceeded` 响应 → 压缩后重发一次；同步与异步路径都成立。
